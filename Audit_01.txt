AUDIT TASK — DATA STORAGE & LIFECYCLE

Цель: проверить готовность приложения к долгосрочному использованию (1–2 года)

Проверить:

1. Есть ли ограничения на:
   - mood_history
   - notesHistory
   - reflections
   - voiceHistory

2. Есть ли:
   - MAX_ENTRIES
   - MAX_DAYS
   - очистка старых данных

3. Есть ли защита от:
   - роста localStorage / IndexedDB
   - деградации offline-ai при больших массивах

4. Используется ли:
   - только recent history (7–30 дней) в analyzeEventImpact

5. Есть ли система:
   - агрегации (месяц / неделя)
   - сохранения долгосрочной статистики

6. Проверить:
   - что происходит при 1000+ записей
   - что происходит при 5000+ записей

7. Выявить:
   - memory leaks
   - узкие места (O(n²) алгоритмы)

Выдать:
- CRITICAL issues
- MEDIUM issues
- SAFE

И предложить минимальный план фиксов без переписывания всей архитектуры.
