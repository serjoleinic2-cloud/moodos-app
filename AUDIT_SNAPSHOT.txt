## 1. CORE JS

### app.js (boot)
- Exposes SystemCore to window
- Registers window.onCloudData callback for Firebase restore
- Imports: navigation, UI, offline-ai, voice, memory, analytics, state, user-profile, onboarding, i18n, avatar, premium-modal, billing-service

### system-core.js (orchestrator)
- handleMoodFlow: analyzes mood, generates insights, patterns, resilience
- Events: MOOD_SUBMIT, SAVE_REFLECTION, VOICE_SAVE → calls scheduleCloudSync()
- All state changes go through SystemCore only

### cloud-sync.js
- syncToCloud(): sends all localStorage data to Firebase via window.Android.saveToCloud()
- scheduleCloudSync(): debounce 2 seconds
- Payload: mood_history, notes_history, reflections, voice_history, photo_history, practice_history, neyra_patterns, profile

### cloud-restore.js
- restoreFromCloud(data): restores data to localStorage
- hasLocalData(): checks if local data exists
- restoreFromCloudIfEmpty(): skip if local data exists (protection)
