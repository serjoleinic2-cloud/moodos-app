Чекпоинт: система тем в Neyra (для новой сессии)

Стек приложения
Capacitor 8 + Vite. Исходники в www/. Сборка: npm run build → npx cap copy android.

Как работают темы
Тема применяется через document.body.setAttribute('data-theme', 'deep-ocean') при старте в app.js:
jsapplyTheme(getTheme()); // вызывается перед initNavigation()
Каждая тема — отдельный CSS-файл в www/css/. Подключены в index.html после style.css:
html<link rel="stylesheet" href="css/style.css">
<link rel="stylesheet" href="css/theme-deep-ocean.css">

CSS-переменные (объявлены в теме, JS читает через window.themeVar)
cssbody[data-theme="deep-ocean"] {
  --theme-bg:           #0a1a2e;
  --theme-card-bg:      rgba(20,45,70,0.95);
  --theme-btn-bg:       #023859;
  --theme-text-primary: #ffffff;
  --theme-text-accent:  #54ACBF;
  --theme-text-muted:   #89CCD8;
  --theme-text-green:   #4caf87;
  --theme-chart-text:   #ffffff;
  --theme-chart-grid:   rgba(84,172,191,0.15);
  --theme-shadow:       0 4px 16px rgba(0,0,0,0.35);
}
JS в insight.js, report.js, stability.js читает их так:
jsfunction chartTextColor() {
  return window.themeVar ? window.themeVar('--theme-chart-text') : '#888';
}
window.themeVar определён в app.js:
jswindow.themeVar = function(name) {
  return getComputedStyle(document.body).getPropertyValue(name).trim();
};

Как создать новую тему

Скопировать theme-deep-ocean.css → theme-НАЗВАНИЕ.css
Find & replace: deep-ocean → НАЗВАНИЕ
Поменять только цвета в переменных вверху файла
Подключить в index.html после style.css
Добавить в settings.js в объект themeLabels:

js'НАЗВАНИЕ': 'Название для пользователя',
