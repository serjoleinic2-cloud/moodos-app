# 🚀 FEATURE: Avatar System (behavior, positioning, interaction)

## 📌 Goal

Создать живого аватара, который:

* не мешает UI
* реагирует на действия пользователя
* даёт микро-поддержку
* усиливает ощущение “я не один”

---

# 🧠 ROLE OF AVATAR

Аватар — это НЕ кнопка и НЕ декор.

👉 Это:

* мягкий помощник
* наблюдатель
* источник короткой поддержки

---

# 🔴 PART 1: POSITIONING

## ✅ Требования:

* position: fixed
* по умолчанию: правый нижний угол
* отступы:

```css
bottom: 80px;
right: 16px;
```

---

## ❗ Ограничения:

* не перекрывает кнопки
* не выходит за экран
* draggable (перетаскиваемый)

---

## Drag:

* следует за пальцем БЕЗ смещения
* сохраняет позицию в localStorage
* ограничен границами экрана

---

# 🔴 PART 2: VISUAL

## ✅ Должно быть:

```html
<div id="avatar-container">
  <div id="avatar-face">🙂</div>
</div>
```

---

## ❌ Запрещено:

* лишние div (effects, wrappers)
* цветные фоны (red, blue)
* debug элементы

---

## CSS:

```css
#avatar-container {
  width: 60px;
  height: 60px;
  border-radius: 50%;
  background: transparent;
}

#avatar-face {
  font-size: 28px;
}
```

---

# 🔴 PART 3: STATES (CRITICAL)

Аватар должен иметь состояния:

---

## 1. IDLE

* лёгкое покачивание / breathing animation
* ничего не говорит

---

## 2. ACTIVE (показ сообщения)

* появляется bubble
* текст 1–2 строки

---

## 3. TAP

* пользователь нажал → короткая реакция

---

# 🔴 PART 4: MESSAGES SYSTEM

## showAvatar(message, options)

```js
showAvatar("Ты сегодня хорошо держишься", {
  type: 'support',
  duration: 3000
});
```

---

## Типы:

* support
* insight
* reminder

---

# 🔴 PART 5: TRIGGERS (ГЛАВНОЕ)

Аватар НЕ говорит сам по себе.

---

## ✅ Должен реагировать на события:

---

### 1. После практики

```js
if (result === 'positive') {
  showAvatar("Рад, что это помогло");
}
```

```js
if (result === 'negative') {
  showAvatar("Окей, давай попробуем что-то другое");
}
```

---

### 2. Первый запуск дня

```js
showAvatar("Я рядом. С чего начнём?");
```

---

### 3. Бездействие (60+ сек)

```js
showAvatar("Хочешь попробовать практику?");
```

---

### 4. Частое использование одной практики

```js
showAvatar("Похоже, тебе помогает спокойствие");
```

---

# 🔴 PART 6: TAP INTERACTION

При нажатии:

```js
onAvatarTap()
```

---

## Поведение:

* показать случайную фразу:

```js
[
  "Я рядом",
  "Ты справляешься",
  "Давай продолжим",
  "Как ты сейчас?"
]
```

---

# 🔴 PART 7: NON-BLOCKING UI

## ❗ КРИТИЧНО

* avatar НЕ блокирует клики
* pointer-events только на avatar-face
* никаких fullscreen контейнеров

---

# 🔴 PART 8: SYSTEM INTEGRATION

Аватар работает через SystemCore:

---

```js
SystemCore.dispatch('AVATAR_SHOW', { message })
SystemCore.dispatch('AVATAR_TAP')
```

---

# 🔴 PART 9: WHAT NOT TO DO

❌ НЕ делать:

* сложный AI
* длинные тексты
* автоспам сообщений
* отдельную систему логики

---

# 🎯 EXPECTED RESULT

Аватар:

* всегда на экране
* не мешает
* реагирует на действия
* даёт короткую поддержку
* ощущается “живым”
