# 🚀 AVATAR V2: Personalization + Context + Intelligence

## 📌 Goal

Сделать аватара:

* персональным
* контекстным
* полезным (а не просто “говорящим”)

---

# 🧠 PRINCIPLE

Аватар должен говорить:

👉 НЕ случайно
👉 А на основе поведения пользователя

---

# 🔴 PART 1: PERSONALIZED MESSAGES (CRITICAL)

## ❗ Сейчас:

общие фразы:

```text
"Рад, что помогло"
```

---

## ✅ Сделать:

использовать данные:

* mood
* result
* practice type

---

## Пример:

```js
if (result === 'positive' && mood === 'anxious') {
  showAvatar("Вижу, при тревоге тебе это помогает");
}
```

```js
if (result === 'negative' && mood === 'sad') {
  showAvatar("Похоже, это не лучший вариант при грусти");
}
```

---

# 🔴 PART 2: MEMORY-BASED INSIGHTS

## 📌 Использовать историю (Memory)

---

## Пример:

если пользователь 3+ раз выбрал одно:

```js
showAvatar("Ты часто выбираешь спокойствие — это работает для тебя");
```

---

## Реализация:

* взять последние N записей
* сгруппировать по category
* найти наиболее частую

---

# 🔴 PART 3: CONTEXT TRIGGERS

## Добавить реакции:

---

### 1. После инсайта:

```js
showAvatar("Интересно, правда?");
```

---

### 2. При бездействии:

```js
showAvatar("Хочешь продолжить?");
```

---

### 3. При возврате в приложение:

```js
showAvatar("Рад, что ты вернулся");
```
