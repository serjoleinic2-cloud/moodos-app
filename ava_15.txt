# 🚀 AVATAR SYSTEM SPEC (implementation contract)

## 📌 Purpose

Аватар — это постоянный UI-элемент, который:

* даёт краткую эмоциональную поддержку
* реагирует на действия пользователя
* НЕ мешает интерфейсу

---

# 🧠 CORE PRINCIPLES

1. Минимальный (маленький, ненавязчивый)
2. Реактивный (не говорит без причины)
3. Краткий (1–2 строки максимум)
4. Не блокирует UI

---

# 🔴 PART 1: STRUCTURE

## DOM:

```html
<div id="avatar-container">
  <div id="avatar-face">🙂</div>
  <div id="avatar-bubble"></div>
</div>
```

---

## ❗ Ограничения:

* Никаких дополнительных wrapper’ов
* Никаких debug-элементов
* Bubble рендерится только при сообщении

---

# 🔴 PART 2: POSITIONING

## Базовая позиция:

```css
position: fixed;
bottom: 80px;
right: 16px;
```

---

## Drag behavior:

* draggable (touch + mouse)
* следует за пальцем БЕЗ offset
* ограничен экраном:

```js
x: 10 → viewportWidth - 60
y: 10 → viewportHeight - 80
```

---

## Сохранение:

```js
localStorage.setItem('avatar_position', { x, y })
```

---

# 🔴 PART 3: VISUAL

## Контейнер:

* размер: 60x60
* полупрозрачный ободок (оставить текущий)
* фон: прозрачный

---

## Face:

* emoji (🙂 по умолчанию)
* центрирован

---

## Bubble:

* появляется рядом
* сторона зависит от позиции:

```js
if (x > screenWidth / 2) → bubble слева
else → справа
```

---

# 🔴 PART 4: STATES

## 1. IDLE

* лёгкая анимация (breathing)
* bubble скрыт

---

## 2. ACTIVE

* bubble виден
* текст сообщения

---

## 3. DRAGGING

* отключаются анимации
* нет сообщений

---

# 🔴 PART 5: API (обязательный контракт)

## showAvatar

```js
showAvatar(message, {
  type: 'support' | 'insight' | 'reminder',
  duration: 3000,
  force: false
});
```

---

## Поведение:

* показывает bubble
* скрывает через duration
* force игнорирует cooldown

---

## hideAvatar

```js
hideAvatar();
```

---

# 🔴 PART 6: EVENTS (SystemCore)

Аватар работает только через события:

---

## Поддерживаемые:

```js
AVATAR_SHOW
AVATAR_TAP
USER_INACTIVE
SCREEN_ENTER
FIRST_OPEN_TODAY
```

---

# 🔴 PART 7: TRIGGERS

## После практики:

```js
positive → "Рад, что это помогло"
negative → "Попробуем другой подход"
```

---

## Первый вход в день:

```js
"Я рядом. С чего начнём?"
```

---

## Бездействие (60 сек):

```js
"Хочешь попробовать практику?"
```

---

## Tap:

случайная фраза из списка:

```js
[
  "Я рядом",
  "Ты справляешься",
  "Продолжай",
  "Как ты сейчас?"
]
```

---

# 🔴 PART 8: COOLDOWN SYSTEM

## ❗ Ограничение:

* не чаще 1 сообщения в 10 сек

---

## Исключение:

```js
force: true
```

---

# 🔴 PART 9: NON-BLOCKING UI

## ❗ КРИТИЧНО

* pointer-events только на avatar-container
* bubble НЕ блокирует клики
* контейнер = 60x60 (НЕ fullscreen)

---

# 🔴 PART 10: WHAT AVATAR MUST NOT DO

❌ НЕ должен:

* спамить сообщениями
* перекрывать UI
* показывать длинные тексты
* иметь собственную бизнес-логику
* хранить данные (только отображает)

---

# 🎯 EXPECTED RESULT

Аватар:

* всегда доступен
* двигается плавно
* не мешает интерфейсу
* реагирует на действия
* даёт короткие, уместные сообщения

---
