Приложение
Neyra (Moodos) — mood-tracker, Android, Capacitor 8 + Vite. Репо: serjoleinic2-cloud/moodos-app. Исходники в www/. Сборка: npm run build → npx cap copy android. FREEZE_PROTOCOL запрещает новые архитектурные слои — только bugfix и изменение существующих модулей.

Рабочий процесс

Claude читает файлы по raw-ссылкам с ?nocache=N в конце
Пишет задания для opencode (локальный AI-кодер)
Никаких догадок — только код-based анализ


Что сделано в этой сессии
i18n и переводы:

home-greetings-ru.js → home-greetings.js (5 языков, читает localStorage app_language)
challengeUI.* → t('challenge_*') во всех i18n-файлах
Письма Нейры: avatar-letter-engine.js — динамический импорт по языку (avatar-letters-{lang}.js)
letter-overlay.js — triggerNames через t(), дата через localeMap
Ключи писем добавлены в все 5 i18n-файлов (letter_card_title, letter_history_title и др.)
Все названия медалей добавлены в все 5 i18n-файлов (medal_*, medals_category_*)
challenge_skipped, challenge_timer_hint, breath_choose_rhythm, back добавлены во все 5 файлов

Billing / Premium:

billing-service.js: .approved() активирует без проверки store.owned(), store.update() при старте, restorePurchases() если не owned
user-profile.js: premiumExpiresAt = Date.now() + 3 days — штамп обновляется при каждом запуске
isPremium(): проверяет runtime-флаг → store.owned() → localStorage fallback
.expired() колбэк удалён (не существует в v13)

Splash-экран:

index.html: буквы N e y r a с инлайн opacity:0
app.js: IIFE анимация — падение букв → пауза → уход вниз → _tryHideSplash
_splashReady = true выставляется после initNavigation()
Страховка: через 4 сек удаляется принудительно

CSS-переменные и темы:

style.css: :root с переменными --theme-* для дефолтной темы
app.js: window.themeVar(name) — читает CSS-переменную
applyTheme(getTheme()) вызывается перед initNavigation() в startApp()
Chart.js defaults устанавливаются через window.themeVar
insight.js, report.js, stability.js: chartTextColor() и chartGridColor() через window.themeVar
Инлайн-цвета в JS заменены на var(--theme-text-primary, ...) и т.д.

Тема Deep Ocean (www/css/theme-deep-ocean.css):
Отдельный файл, подключён в index.html после style.css.
Стандарт:

Фон: linear-gradient(160deg, #0d2137, #0a1a2e)
Карточки: rgba(20,45,70,0.95)
Кнопки: #023859
Текст белый: #ffffff
Текст голубой: #54ACBF
Текст мuted: #89CCD8
Зелёный: #4caf87 (везде оставить)
Тени: 0 4px 16px rgba(0,0,0,0.35)

Покрыто в теме: карточки, навигация, панели меню/практик, кнопки, триггеры, слайдер, треки медитации, flip-карточки, история, попапы, PDF-отчёт, премиум-экран, настройки, медали, как это работает, хранение данных, календарь, дыхание, медитация, splash, письма Нейры, Chart.js.
Как создать новую тему:

Скопировать theme-deep-ocean.css → theme-НАЗВАНИЕ.css
Find & replace: deep-ocean → НАЗВАНИЕ
Поменять переменные --theme-* вверху файла
Подключить в index.html
Добавить в settings.js в themeLabels

Navigation (меню и практики):

navigation.js: openMenu() и openToolsMenu() раскрывают панели на весь экран (top:0, height:100vh, paddingTop: calc(env(safe-area-inset-top,24px) + 24px))
Оверлеи отключены при полноэкранных панелях
closeMenu() и closeToolsMenu() используют bottom: -100vh

Edge-to-edge / safe area:

index.html: viewport-fit=cover добавлен в meta viewport
app.js: JS-фолбэк --nav-bar-height через window.visualViewport
.bottom-nav: padding-bottom: calc(max(env(...), var(--nav-bar-height,16px)) + 38px)
.screen: padding-bottom: calc(120px + max(env(...), var(--nav-bar-height,16px)))
