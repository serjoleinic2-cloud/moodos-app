# 🚨 TASK: Fix Support Texts (Insight + Centering + Button overlap)

## 📌 Goal

Исправить 3 проблемы:

1. Нет записи в Insight
2. 3 кнопки (Спокойствие / Поддержка / Молитва) не по центру
3. Кнопки "Помогло / Не помогло" наезжают друг на друга

---

# 🔴 PART 1: FIX INSIGHT (CRITICAL)

## ❗ Проблема:

данные НЕ отображаются в Insight

---

## ✅ Решение:

НАЙТИ рабочую практику (например `meditation.js`)

---

## 👉 СКОПИРОВАТЬ pipeline 1:1

### После нажатия:

```js
Memory.save('practice', {
  type: 'practice',
  name: i18n.t('practice_support_text'),
  result: payload.result,
  date: Date.now()
});
```

---

### И СРАЗУ:

```js
SystemCore.dispatch('GENERATE_INSIGHT', {
  type: 'practice',
  result: payload.result
});
```

---

## ❗ ЗАПРЕЩЕНО:

* type: 'support_text'
* любые кастомные форматы

---

## ✅ ОБЯЗАТЕЛЬНО:

использовать `type: 'practice'`
(иначе Insight не работает)
