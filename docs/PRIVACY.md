# Privacy Policy

## 1. Overview

* App Neyra is an offline-first mood tracking application
* By default, all data is stored locally on the user's device

---

## 2. Local Data Storage

* Mood entries, reflections, and history are stored on-device
* No data is sent to servers unless user enables cloud features

---

## 3. Cloud Storage (Firebase)

The App may optionally store your data in the cloud using Firebase (Google LLC) if you enable cloud backup.

### What data is stored in the cloud:
- Mood entries (mood history)
- Reflections and notes
- Voice recordings (if used)
- Photos (if used)
- Pattern analysis data
- Practice session history

### When data is sent:
- Data is automatically synced after user actions (saving mood, reflection, voice note)
- Sync occurs only if cloud features are enabled with your consent

### Purpose:
- Backup your data
- Restore data when reinstalling the app
- Sync across devices

### Data processing:
- Data is stored in Firebase Firestore
- Data may be associated with your account

### Security:
- Data is transmitted over secure HTTPS connections
- Access is restricted to your account

### User control:
- You can disable cloud sync at any time
- You can request deletion of your cloud data

### Third-party:
- Firebase (Google LLC) may process data according to their Privacy Policy: https://policies.google.com/privacy

---

## 4. User Consent

By enabling cloud features, you consent to storing your data in Firebase (Google LLC).

---

## 5. Authentication

* Google Sign-In may be used to identify the user
* Only basic account data is accessed (email / ID)

---

## 6. User Rights

* Access your data
* Delete your data
* Export your data
* Revoke consent at any time

---

## 7. Data Security

* Local storage is protected by device security
* Cloud data is handled by Firebase security standards

---

## 8. Children's Privacy

* Not intended for children under 13

---

## 9. Changes

* Policy may be updated
* Users will be informed via app updates
