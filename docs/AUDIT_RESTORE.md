# АУДИТ: Restore & Merge логика

## ЦЕЛЬ

Проверить работоспособность функций восстановления, хранения и добавления данных в FREE и PREMIUM версиях.

---

## ЧАСТЬ 1: Экспорт данных

### 1.1 FREE версия
- [ ] Создать бэкап без Premium (нажимаю Export)
- [ ] Проверить: появляется ли cooldown (3 дня)?
- [ ] Если данных мало - экспорт работает?
- [ ] Файл сохраняется через Share dialog?

### 1.2 PREMIUM версия
- [ ] Активировать Premium
- [ ] Создать бэкап с Premium
- [ ] Проверить: есть ли cooldown?
- [ ] Файл сохраняется?

### Ожидаемое поведение:
| Версия | Cooldown | Ограничения |
|--------|----------|--------------|
| FREE | 3 дня после last_backup_time | Лимит на экспорт |
| PREMIUM | Нет | Без ограничений |

---

## ЧАСТЬ 2: Импорт данных

### 2.1 Импорт ZIP
- [ ] Выбрать ZIP файл (с расширением или без)
- [ ] Нажать "Восстановить"
- [ ] Данные добавляются (merge) или заменяются?

### 2.2 Импорт JSON
- [ ] Выбрать .json файл
- [ ] Нажать "Восстановить"
- [ ] Данные добавляются?

### Ожидаемое поведение:
- Данные должны **добавляться** по timestamp, а не заменяться
- Новые записи из бэкапа должны добавляться в хронологию
- Старые записи должны сохраняться

---

## ЧАСТЬ 3: Merge логика

### 3.1 Проверка merge
- [ ] Создать 2 записи с настроением
- [ ] Удалить приложение
- [ ] Восстановить из бэкапа
- [ ] Сколько записей в истории? (должно быть больше чем в бэкапе — новые + старые)

### 3.2 Проверка дубликатов
- [ ] Если запись с ts=123 уже есть — она не должна дублироваться
- [ ] Проверить: нет ли повторов в истории?

### Ожидаемое поведение:
```
Текущие: [ts:100, ts:200]
Бэкап:   [ts:50, ts:150]
Результат: [ts:50, ts:100, ts:150, ts:200] (4 записи)
```

---

## ЧАСТЬ 4: Premium vs FREE разница

### 4.1 FREE
- [ ] Нет доступа к cloud backup
- [ ] Ограничение на restore (только локальный)

### 4.2 PREMIUM
- [ ] Cloud backup активен
- [ ] Бэкап включает больше данных?
- [ ] Restore из cloud работает?
