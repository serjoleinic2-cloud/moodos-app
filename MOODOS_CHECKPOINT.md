# MoodOS — Чекпоинт для новой сессии

## 👤 КТО ТАКОЙ СЕРГЕЙ

- **Не программист.** Работает через GitHub web-интерфейс (редактирует файлы прямо там)
- Сборка: GitHub → Android Studio → тест на реальном Android-устройстве
- Репо: `https://github.com/serjoleinic2-cloud/moodos-app`
- Язык общения: **только русский**
- Когда что-то не работает — говорит просто "не сработало". Нужно разбираться что именно.

## 🛠 КАК С НИМ РАБОТАТЬ

- Давать файлы готовыми — **полный файл целиком**, без сокращений типа "// остальное без изменений"
- Объяснять коротко и по делу, без воды
- **Никогда не просить вставить код вручную** — только заменить файл целиком
- Читать файлы из репо только по ссылкам, которые присылает Сергей, с `?nocache=N` (менять N каждый раз — GitHub кэширует)
- Если Сергей говорит "в файле нет этой строки" — верить ему, не инструменту
- Перед тем как что-то менять — **прочитать актуальную версию файла** из репо

## 📱 ФИЛОСОФИЯ ПРИЛОЖЕНИЯ

MoodOS — **молчаливый наблюдатель**, не советчик. Ключевые принципы:

- Не даёт советов которые не просили
- Не давит, не оценивает, не лечит
- Просто рядом — помогает замечать паттерны
- Тёплый, человечный тон. Не клинический.
- Приватность: все данные **только на устройстве** (localStorage), никакой аналитики, никаких серверов
- Для людей 16+, часто принимающих психиатрические препараты или переживающих трудный период

## ⚠️ КРИТИЧЕСКИЕ ПРАВИЛА — НЕЛЬЗЯ НАРУШАТЬ

1. **`navigation.js`**: `closeAllOverlays()` импортируется из `./screens/pdf-report.js` и вызывается в каждом `openScreen()`. Без этого модалки не закрываются.
2. **`app.js`**: НЕ должен импортировать i18n напрямую на верхнем уровне если i18n.js вдруг отсутствует — это вешает всё приложение
3. **`onboarding.js`**: finish() вызывает `saveProfile()` + `markOnboardingDone()` + `onComplete()` — **БЕЗ перезагрузки страницы**
4. **Не трогать** `state.js`, `services/*`, `ai/*` без крайней необходимости — там рабочая логика

- `i18n.js` есть в репо ✅
- `app.js` старый — не импортирует i18n, не запускает onboarding ❌
- `index.html` старый — строки захардкожены, нет скрипта переводов ❌
- Попытки залить новые `app.js` и `index.html` — "не сработало" (причина неизвестна)

### Что значит "не сработало" — нужно выяснить:
- Приложение вообще не запускается?
- Запускается но онбординг не показывается?
- Онбординг показывается но переводы не работают?
- Ошибка в Android Studio при сборке?

**Шаг 1:** Сергей присылает ссылки на актуальные файлы в репо:
- `app.js?nocache=X`
- `index.html?nocache=X`
- `onboarding.js?nocache=X`

**Шаг 2:** Читаем их, понимаем реальное состояние.

**Шаг 3:** Выясняем точно — что именно "не сработало". Какое поведение видит Сергей на устройстве.

**Шаг 4:** Действуем от простого к сложному. Возможно нужна совсем другая стратегия подключения i18n — без изменений index.html, только через app.js.
