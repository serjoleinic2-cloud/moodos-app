## 🧠 Философия приложения

MoodOS — Android-приложение для отслеживания эмоционального состояния. Не терапия, не дневник — **инструмент осознанности в моменте**. Пользователь фиксирует настроение, использует практики для саморегуляции, видит паттерны. Всё локально, без серверов, без аккаунтов — данные только на телефоне.

**Целевая аудитория:** люди, которым важно понимать себя, но не готовые к тяжёлым дневникам или психологическим приложениям. Простота — главный приоритет.

**Стек:** Capacitor (WebView) → Android APK. Чистый JS (ES modules), никакого React/Vue. CSS с неоморфным стилем (мягкие тени, пастельные тона).

## ⚠️ Критические правила (обязательно соблюдать)

1. **`navigation.js`**: `closeAllOverlays()` — импортируется из `./screens/pdf-report.js`, не из другого места
2. **Кнопка OK** — логика только в `home.js` через `updateStabilityHistory(moodValue)`
3. **`state.js`, `services/*`, `ai/*`** — не трогать без крайней необходимости
4. **Слайдер и кнопка OK клонируются** в `home.js` — это предотвращает дублирование событий
5. **Даты** — формат `DD.MM.YYYY` везде (не локализованные строки)
6. **nocache параметр** при загрузке файлов из GitHub — текущий актуальный: **21**. Каждый раз увеличивать на 1 при повторной загрузке того же файла
7. **Полные файлы или точечные правки с указанием места** — Сергей вставляет через GitHub web-интерфейс

## 🔧 Нюансы работы с Сергеем

1. **Не программист** — объяснять просто, без лишних технических деталей
2. **GitHub web-интерфейс** — нельзя запустить команды локально. Всё через "создать файл" / "редактировать файл" в GitHub
3. **Полные файлы предпочтительнее** — проще вставить целиком, чем делать точечные правки
4. **Если точечная правка** — обязательно указывать: найти такой-то текст → заменить на вот этот
5. **Проверка через телефон** — нет localhost, только реальный APK через Android Studio
6. **nocache** — при запросе файла с GitHub добавлять `?nocache=N` и увеличивать N каждый раз
7. **Язык общения** — русский
8. **Сборка может занимать время** — если баг не воспроизвёлся, возможно старая версия APK
9. **localStorage** — все данные хранятся там. При тестировании можно очистить через DevTools → Application → Clear Storage

## 💡 Технические заметки для следующего разработчика

- **WebM audio без duration** — Android WebView не может прочитать длину webm-файла из base64 пока не буферизует. Решение: сохранять `duration` в момент записи (уже сделано в voice.js)
- **ES modules** — все файлы используют `import/export`. GitHub Pages / Capacitor требуют `type="module"` в `<script>` тегах
- **Клонирование кнопок** — в home.js слайдер и кнопка OK клонируются чтобы убрать старые event listeners. Это не баг — это намеренно
- **`calculateGoldenHour()`** — возвращает `{start, end}` или `null` (не просто строку!)
- **i18n** — `t("ключ")` возвращает строку. Если ключ не найден — возвращает сам ключ. Не массив, не объект
