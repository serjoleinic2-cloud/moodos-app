# 🧠 СТРУКТУРА BRAIN v2 (СТРОГО)

PROJECT_BRAIN.md должен быть переписан в виде:

---

## 1. CORE PURPOSE

(зачем существует Neyra — 1–2 абзаца максимум)

---

## 2. SYSTEM PRINCIPLES

(только инварианты, 5–7 пунктов максимум)

Пример:

* система не хранит недостоверное состояние
* UI не управляет бизнес-логикой
* данные валидируются при входе

---

## 3. SYSTEM MODEL

Чёткое описание:

* что есть в системе (entities)
* как они связаны

Без лишних слов

---

## 4. STATE RULES

* как хранится состояние
* где может ломаться консистентность
* какие есть ограничения

---

## 5. ACCESS / ENTITLEMENT MODEL (КРИТИЧЕСКОЕ)

Отдельный блок:

* что такое premium
* где он проверяется
* как он влияет на данные

👉 ОБЯЗАТЕЛЬНО учти баг из аудита:
premium закончился → данные остались

---

## 6. WHAT IS NOT ALLOWED

Очень важно:

* что система НЕ должна делать
* (например: хранить premium-контент без доступа)
